把想做的事，
变成今天能做完的事

TaskFlow 围绕「计划 → 执行 → 复盘 → 成长」闭环，把任务、目标、课表与番茄钟串成一套可持续的节奏。它不催你，只是每天陪你把重要的事往前推一点。

How it works

一套闭环，四个环节

每一步都有对应工具，数据在本地自动串联

01

🎯 计划

从目标拆解到每日安排，生成一份可执行的当天计划。

02

✅ 执行

任务列表 + 番茄钟，专注当下；逾期任务自然周归档。

03

📄 复盘

周报、评分与输入输出复盘，让每次完成都有沉淀。

04

📈 成长

连续打卡、等级与能力雷达，看见长期的自己。

Features

核心功能一览

每一个界面都为「少一点干扰、多一点推进」而设计 · 真实界面截图陆续补上

01 · 计划

智能每日计划

打开就是一份排好的今天。四宫格指标、本周条、任务清单在一个页面里，重要的事自然浮到最上面。

  • 按紧要程度与目标关联生成当天安排
  • 跨天历史浏览，点日期查看任意一天
  • 任务可编辑、推迟、拖动排序，逾期自动归档
入口：侧栏「今日计划」
taskflow / today plan

02 · 感知

感知式 AI 教练

不是通用聊天，而是读过你任务、目标与身份画像的教练。它会结合当天上下文给建议，帮你拆开卡住的事。

  • 右侧抽屉式对话，不打断当前任务
  • 身份校准对话，调整称呼与说话语气
  • 模型接口可自行配置，数据留在本地
入口：右上角「AI 教练」
taskflow / ai coach

03 · 执行

番茄钟与投入量化

一个计时器，把「今天做了多久」从感觉变成记录。完成时自动关联到当前任务，复盘时不再靠回忆。

  • 专注计时与休息循环，进度环实时可见
  • 客观记录与手填投入并列，互相校准
  • 连续打卡与等级，让长期坚持看得见
入口：侧栏「番茄钟」
taskflow / focus timer
📷番茄钟专注界面截图待替换为真实截图 · 建议 16:10 横向
04 · 成长

复盘与能力成长

完成不是终点。周报、评分、记忆锚点与能力雷达，把每一次推进沉淀成可回看的成长轨迹。

  • 输入输出成对复盘，形成闭环记录
  • 能力雷达与身份画像，看见长期变化
  • 记忆锚点配上画面与一句话，让重要的事被记住
入口：侧栏「周报 / 成长 / 复盘」
